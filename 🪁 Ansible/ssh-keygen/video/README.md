Dalam video ini kita akan mempelajari konsep dasar SSH-Keygen (Secure Shell Key Generator), cara membuat pasangan kunci kriptografi untuk autentikasi SSH tanpa password, setup topologi star dengan VMware, konfigurasi SSH server di Debian 12, membuat dan menyalin SSH key ke remote server, serta testing koneksi SSH menggunakan key-based authentication. Video ini cocok untuk system administrator dan DevOps engineer pemula yang ingin memahami dasar-dasar keamanan SSH dan network automation menggunakan key pair authentication dengan praktik langsung step-by-step.

192.168.1.0/24

💻 Device Configuration:  
PC (SSH Client): 192.168.1.10/24  
SRV1 (SSH Server): 192.168.1.1/24

🔐 SSH-Keygen Configuration:  
Authentication Method: Public Key Authentication  
Key Type: RSA (default)  
Private Key Location: ~/.ssh/id_rsa  
Public Key Location: ~/.ssh/id_rsa.pub  
Target Servers: 192.168.1.1, 192.168.1.2
