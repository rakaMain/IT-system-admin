Dalam video ini kita akan mempelajari konsep dasar **Ansible** sebagai tool automation IT open source, perbedaan *Ad-hoc command* dan *Playbook*, cara instal dan konfigurasi dasar Ansible di Debian 12, setup topologi star dengan VMware, konfigurasi SSH key authentication, membuat `inventory` file dan `ansible.cfg`, serta testing koneksi dan menjalankan task automation dasar. Video ini cocok untuk system administrator dan DevOps engineer pemula yang ingin memahami automation server management dengan praktik langsung step-by-step menggunakan Ansible.

🌍 Network Topology: Star Topology  
LAN Segment menggunakan NAT

💻 Device Configuration:  
- Ansible Server (Control Node): Debian 12  
- SRV1 (Managed Node): Debian 12 dengan OpenSSH Server  
- SRV2 (Managed Node): Debian 12 dengan OpenSSH Server

⌛ Time Code:  
00:00 intro & teori  
05:18 setup ulang topologi  
11:20 praktik ansible

⚙️ Ansible Configuration:  
- Inventory Group: `[dbserver]`  
- SSH Authentication: SSH Key-based (`id_ansible`)  
- Config File: `ansible.cfg`  
- Inventory File: `inventory`

📦 Commands yang Digunakan:  
- Install Ansible  
- Setup SSH key authentication  
- Create inventory file dengan grup `[dbserver]`  
- Configure `ansible.cfg` (inventory path & `private_key_file`)  
- Test koneksi dengan `ping` module  
- Gather facts dari managed nodes  
- Update package cache  
- Install/remove packages menggunakan `apt` module
